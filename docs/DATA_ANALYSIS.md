## ประเด็นคุณภาพข้อมูล

1. **Data มี 387 รายการ รวม 2 รายการไม่มี TAG**: แถว 134–135 คือ Kiln Shell Scanner K3 และ K4 ต้องไม่ทิ้งแถวเหล่านี้เพียงเพราะ TAG ว่าง แต่ควรเติม TAG ก่อนใช้เชื่อมกับระบบอื่น TAG ที่ไม่ว่างไม่ซ้ำภายในแต่ละขอบเขต
2. **Data!S390 = SUM(S3:S387)** ข้าม S388 และ S389 (AIAX94103, AIAX98103) มีแผนพฤศจิกายนรายการละ 1 งาน ทำให้ยอดพฤศจิกายน 181 แทน 183 และทั้งปี 724 แทน 726
3. **SSCC Master Plan!Y2:AB2** รวมถึงแถว 188 เท่านั้น ข้ามส่วนท้ายที่ยังมีเครื่องมือ ทำให้แผน 304 แทน 327 และผลจริง 145 แทน 154
4. **Actual ใน Critical ไม่ใช่จำนวนที่นำมาบวกโดยตรง**: ต้องใช้ตรรกะ COUNT ของ Excel นับเฉพาะตัวเลขรวม 0 และค่าติดลบ มี No cal. 8 ช่องที่ไม่นับเป็นงานสำเร็จ เก็บค่าอ่านและข้อความต้นฉบับแยกจากจำนวนงาน
5. **Data กับ Critical ไม่ตรงกันทุก TAG**: เช่น A1J07A9 อยู่ Rawmill ใน Data แต่ Crusher ใน Critical ชื่อประเภทและแผนความถี่ต่างกันด้วย ไม่รวมสองขอบเขตหรือเปลี่ยนชื่อโดยเงียบ ๆ
6. **รายการไม่มีแผนทั้งปี**: Data 84 รายการ และ Critical 58 รายการ ยังตัดสินไม่ได้ว่าไม่ต้องสอบเทียบหรือยังไม่ลงแผน โดยเฉพาะความถี่ Annual SD / 3Y จึงต้องตรวจสอบกับเจ้าของแผน
7. **เวลาของข้อมูลต่างกัน**: Data มีผลถึงกันยายน Critical มีถึงมิถุนายน ไม่ยืนยันสถานะ ณ วันปัจจุบัน และไม่มีวันที่สอบเทียบรายวัน
8. **ไม่มี tolerance / ผลตัดสินผ่าน**: ค่า 1 อาจใช้แทนเครื่องหมายทำแล้ว จึงไม่ใช้ค่าตัวเลขเพื่อระบุผ่าน/ไม่ผ่านหรือเป็น % error โดยอัตโนมัติ
9. **ไม่มีปริมาณผลผลิต ชั่วโมงหยุดเครื่อง หรือ OEE**: รายงานนี้แสดงความพร้อมด้านการสอบเทียบสำหรับ Production ไม่สร้างตัวเลขผลผลิตขึ้นเอง

## นิยามที่เว็บไซต์ใช้

- แผน YTD = ผลรวมจำนวนงานแผนตั้งแต่มกราคมถึงเดือนรายงาน
- ผลจริง YTD = ผลรวมจำนวนงานจริงในช่วงเดียวกัน
- งานตรงเดือนแผน = รวม `min(plan, actual)` ต่อเครื่องมือต่อเดือนในช่วงรายงาน
- อัตราบันทึกตรงเดือนแผน = งานตรงเดือนแผน / แผน YTD (ไม่มีแผนแสดง “—”)
- งานนอกแผน = รวม `max(actual - plan, 0)` ต่อเครื่องมือต่อเดือน
- ช่องว่างแผน = รวม `max(plan - actual, 0)` ต่อเครื่องมือต่อเดือน ไม่หักกลบข้ามเครื่องมือหรือเดือน
- Annual progress = งานตรงเดือนแผนตลอด 12 เดือน / แผนทั้งปี ใช้ข้อมูลทั้งปีแม้เลือกเดือนรายงานก่อนธันวาคม

การบันทึกตรงเดือนเป็นเพียงตัวชี้วัดจากข้อมูลรายเดือน ไม่รับรองว่าทำทันวันที่กำหนด เพราะต้นฉบับไม่มีวันครบกำหนดและวันดำเนินงานจริง
